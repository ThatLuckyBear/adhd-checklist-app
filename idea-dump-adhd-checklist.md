Ideal App Experience
</summary>

  The vision for what this app would look and feel like to give a starting point.

  ### How I Imagine it Working
  - You open the app and are greeted with the todo builder.
    - There are a few tasks that are highlighted as overdue with options to add them to your todo list for the day, mark as "already did this" and "another day"
      - if ignored they just stay in the list
    - User has "automatically add all daily tasks" so the list already has those tasks set
      - some tasks are highlighted in red since it's been more than 2 days since they've performed that "daily" task and it gets floated to the top of the list as a priority
    - User picks one of the tasks from the red list and adds it to their todo list for the day as well
    - user presses "ready to start my day" and the app does it's thing and creates the list
    - User goes through their day and checks off all the stuff they've done
    - At a user specified time the app reminds them it's time to cool off for the day
    - User clicks "done for today"
    - App gives them a kudos for their effort and tells them they'll see them tomorrow!
  ### First Experience
  - Open the app greeted by tutorial
    - add items
    - set frequency
    - create todo list
    - set notification to pop into the app first thing tomorrow
  - user adds a handful of tasks and does them

### Check In/Reminders!
New idea 8/14/26
Some things you just need to check. Do I need toilet paper? When was the last time I washed my water bottle? 
If the app asks and after checking the user answers yes or no and the app automatically marks the last time it was checked and will check in again at a later date. If yes the app will offer to add a todo item for "put toilet paper on the shopping list"

the point is that sometimes you don't need to do something but you should probably know how long it's been since you've checked. I often buy too much mayo because the one in the fridge runs out but there's already shelf stable mayo in the pantry. Or I'll forgo buying toilet paper or oat milk twice because I'm totally sure I checked yesterday and that was more than a week ago.
